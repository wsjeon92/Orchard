
## 파일 직접 연결

내보내기·가져오기를 매번 하는 대신, 디스크의 `.json` 파일 하나를 그래프의 자리로 삼을 수 있다.
상단바의 **`파일 연결`** 을 누르고 파일을 고르면 된다.

- 브라우저에서 고치면 → 0.4초 뒤 파일에 쓴다 (연달아 고쳐도 쓰기는 한 번으로 묶인다)
- 파일이 바깥에서 바뀌면 → 1~2초 안에 브라우저가 따라온다

서버는 필요 없다. 브라우저의 File System Access API 를 쓴다. **Chrome·Edge 에서만** 되고,
안 되는 브라우저에서는 버튼이 숨고 예전처럼 내보내기·가져오기를 쓴다. 폰 뷰어에서도 숨는다.

### 알아둘 것

- 파일이 바뀌었는지 알려 주는 장치가 브라우저에 없어서 **1.2초마다 들여다본다.** 그래서
  '즉시'가 아니라 1~2초 안에 따라온다.
- **브라우저에 아직 안 쓴 변경이 있으면 그쪽이 이긴다.** 바깥 변경은 그 다음 차례에 읽는다.
  한 사람이 쓰는 도구라 양쪽을 동시에 고치는 일은 드물지만, 규칙은 이렇다.
- 반쯤 쓰인 파일을 읽으면 JSON 이 깨져 있다. 그런 경우는 **무시하고 다음 번에 다시 본다** —
  깨진 내용으로 그래프를 덮어쓰지 않는다.
- 새로고침하면 브라우저가 파일 접근 권한을 다시 물을 수 있다. 버튼이 `파일 다시 연결` 로
  바뀌며, 눌러서 허용하면 이어진다. (권한 창은 사용자가 누른 직후에만 뜰 수 있다)
- 처음 연결할 때 파일에 이미 그래프가 있으면 **어느 쪽을 살릴지 묻는다.**

### MCP 로 가는 길

이 기능이 생기면서 그래프가 파일 하나로 모였다. MCP 서버를 붙일 때 그 서버도 같은 파일을
읽고 쓰면 되고, 브라우저는 폴링으로 따라온다 — 중간에 별도의 서버나 API 가 필요 없다.
