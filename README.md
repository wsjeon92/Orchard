# Orchard

생각을 심고, 돌보고, 거두는 곳. 설익은 연구 아이디어를 **너비**와 **깊이**
두 축으로 디벨롭해 착수할 수 있는 형태까지 끌고 가는 그래프 도구다.
서버도 계정도 없이 브라우저 안에서만 돌아가고, 작업은 자동 저장된다.

- **너비** — 키워드끼리 잇고, 그 교차에 이름을 붙여 새 키워드로 승격한다.
  단백질 × 디자인 → `단백질 디자인`
- **깊이** — 아이디어 하나를 질문 → 가설 → 접근 → 검증 → 리스크로 전개한다.

조사와 판단은 사용자가 한다. AI 호출은 들어 있지 않다.

---

## 개발

```bash
npm install
npm run dev        # 개발 서버
npm run build      # 타입 검사 + 빌드 → dist/index.html
npm run preview    # 빌드 결과 미리보기
npm run typecheck  # 타입만 검사
```

빌드 결과는 **HTML 한 파일**(`dist/index.html`)이다. 정적 호스팅에 그대로 올라가고,
내려받아 더블클릭해도 열린다.

## 배포

세 가지 중 편한 쪽을 쓰면 된다. 어느 쪽이든 빌드 명령은 `npm run build`,
배포할 폴더는 `dist` 다.

**GitHub Pages** — `.github/workflows/deploy.yml` 이 들어 있다.
저장소 Settings → Pages → Source 를 **GitHub Actions** 로 바꾸고 `main` 에 푸시하면 끝.
주소는 `https://<사용자>.github.io/orchard/` 가 된다.
(`vite.config.ts` 의 `base: "./"` 덕에 하위 경로에서도 동작한다.)

**Netlify** — 저장소를 연결하면 `netlify.toml` 을 읽어 알아서 빌드한다.

**Vercel** — 저장소를 연결하면 `vercel.json` 을 읽는다.

**그냥 파일로** — `dist/index.html` 하나만 어디든 올리거나 그대로 열어도 된다.

## 소스 구조

| 파일 | 하는 일 |
| --- | --- |
| `types.ts` | 노드·엣지·보기 설정 타입 정의 |
| `kinds.ts` | 노드 종류별 이름·색·모양, 깊이 항목 순서, 검색 사이트 |
| `state.ts` | 전역 상태, localStorage 저장·불러오기·마이그레이션, 저장본 |
| `geom.ts` | 좌표·선분·겹침 계산, 그룹 박스 레이아웃 |
| `graph.ts` | 그래프 조회와 변경 (이웃, 집중 범위, 접기, 노드·엣지 추가/삭제, 승격, 그룹, 하위 키워드) |
| `labels.ts` | 엣지 이름 겹침 회피 |
| `render.ts` | 전체 렌더, 엣지 그리기, 뷰포트 |
| `anim.ts` | 위치 보간 애니메이션 |
| `panel.ts` | 오른쪽 사이드 패널 |
| `interact.ts` | 포인터·키보드 상호작용 |
| `minimap.ts` | 미니맵 |
| `history.ts` | 실행 취소 / 다시 실행 |
| `modals.ts` | 입력창, 내보내기·가져오기, 저장본 목록, 보기 설정 |
| `dom.ts` | DOM 참조와 조립 헬퍼 |
| `main.ts` | 배선과 부트 |

### 알아둘 만한 설계 결정

**애니메이션은 CSS 가 아니라 JS 보간이다.** SVG `<line>` 의 좌표는 CSS 트랜지션
대상이 아니라서, CSS 로 노드만 움직이면 선이 따라오지 못하고 튄다. 그래서 표시
좌표(`_rx`, `_ry`)를 JS 에서 목표 좌표로 수렴시키고 노드·선·라벨을 같은 프레임에
함께 그린다 (`anim.ts`, `render.ts#paint`).

**엣지 이름 회피는 목표 좌표 기준으로 푼다.** 애니메이션 중간 위치로 풀면 움직임이
멈춘 뒤 그 해답이 맞지 않아 결국 겹친 채로 남는다 (`labels.ts`).

**저장 키는 절대 바꾸지 않는다.** 구조가 바뀌면 `normalize()` 로 올린다. 키를 바꾸면
사용자 데이터가 그냥 사라진다. 예전 키들은 `LS_OLD` 에서 한 번만 끌어온다.
프로젝트 이름이 Orchard 로 바뀐 뒤에도 `kwgraph.` 접두어를 그대로 쓰는 이유가 이것이다.

**실행 취소는 `save()` 에 걸려 있다.** 제목·메모 입력은 전체 렌더를 거치지 않고
`save()` 만 부르기 때문에, 거기 두어야 빠짐이 없다 (`state.ts`, `history.ts`).

## 테스트

Playwright 로 빌드 결과(`dist/index.html`)를 직접 띄워 검증한다.

```bash
npm run build
cd test && for f in smoke*.py; do python3 -I "$f"; done
```

| 파일 | 다루는 것 |
| --- | --- |
| `smoke.py` | 예전 저장 키 승계, 하이퍼엣지, 저장본 |
| `smoke2.py` | 하위 키워드 계층, 순환 차단 |
| `smoke5.py` / `smoke6.py` | 그룹 — 드롭다운 추가, 직접 입력 |
| `smoke7.py` | 접기, 미니맵, 집중 깊이, 검색, 텍스트 페이드, 연결 수 크기 |
| `smoke8.py` | 실행 취소 / 다시 실행 |
| `smoke9.py` / `smoke11.py` / `smoke12.py` | 엣지 이름 겹침 회피 |
| `smoke10.py` | 애니메이션 |
| `smoke13.py` | 엣지 이름 선 위 스냅 |

브라우저 콘솔과 테스트에서 쓰라고 `window.Orchard` 로 내부를 열어 두었다.

## 단축키

| 키 | 동작 |
| --- | --- |
| 빈 곳 더블클릭 | 키워드 추가 |
| 노드 오른쪽 점 드래그 | 연결 (엣지 허브에 떨어뜨리면 그 엣지에 합류) |
| 노드를 다른 노드 위로 드래그 | 그룹 |
| Shift + 클릭 | 여러 개 골라 한 엣지로 묶기 |
| 노드 아래 ▾ | 하위 접기 / 펼치기 |
| 엣지 이름 드래그 | 선 위에서 위치 조정 (더블클릭하면 자동으로) |
| `F` | 집중 모드 |
| `Delete` | 삭제 |
| `Ctrl/Cmd + Z` / `Shift + Z` | 실행 취소 / 다시 실행 |
| `Ctrl/Cmd + F` | 검색 |
| 휠 | 확대·축소 |
